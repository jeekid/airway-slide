Emergency Airway — Assessment → RSI / DSI → Failed Airway

One-slide cheat sheet · 16:9

1 Basic Assessment

  • A patency / FB / blood / swelling
  • B SpO₂ · RR · breath sounds · accessory m.
  • Position sniffing；obese → ramped（ear–sternal）
  • Pre-Ox NRB flush rate ＋ NC 15L；shunt → BVM + PEEP valve / NIV
  • Apneic O₂ NC 15L 全程開到管子進去（NO-DESAT）
  • Plan A→B→C→D（DAS 2015，每階段上限後 escalate）

2 Difficult Airway — 4 情境 4 口訣

Laryngoscopy LEMON · Look / Evaluate 3-3-2 / Mallampati / Obstruction / Neck mobility
Mask vent MOANS · Mask seal / Obese·OSA / Age>55 / No teeth / Stiff lungs
SGA (LMA) RODS · Restricted opening / Obstruction / Distorted / Stiff
Cricothyro. SMART · Surgery / Mass / Access·anatomy / Radiation / Tumor
3-3-2：mouth opening 3 指 · hyoid→chin 3 指 · thyroid→floor of mouth 2 指

3 RSI — 7 Ps

  1. Preparation · SOAP-ME（Suction / O₂ / Airway / Pharm / Monitor·EtCO₂）
  2. Preoxygenation · 3 min FiO₂ 1.0 ／ 8 VC ／ apneic NC
  3. Pre-treatment · 視情況（fentanyl, lidocaine — 不常規）
  4. Paralysis + Induction
    Etomidate 0.3 ｜ Ketamine 1–2 ｜ Propofol 1.5 mg/kg
    Sux 1.5 mg/kg ｜ Roc 1.2 mg/kg（RSI 用高劑量）
  5. Positioning · sniffing / ramped
  6. Placement + Proof · EtCO₂ waveform 是金標準
  7. Post-intubation · sedation · lung-protective vent · CXR

! Physiologically Difficult Airway — 「會在管子周圍 arrest 的病人」

Hypoxemia
shunt → preox 拉不上來
NIV / CPAP preox · ramped · DSI · ECMO 考慮
Hypotension
RSI 藥 + PPV → peri-intubation arrest
Ketamine > etomidate · induction ↓ 50 % · push-dose pressor（epi 10 μg / phenyl 100 μg）· 補液
Acidosis
apnea → pH 崩 → arrest
維持自呼吸 / awake / DSI · 插管後 match MV · pH<7.1 考慮 bicarb
RV failure / pHTN
PPV ↑PVR → RV 衰竭
avoid hypoxia / hypercarbia · ↓ PEEP · preload neutral · iNO · epoprostenol
口訣：HOP-killers（Hypoxia · Optimize hemodynamics · pH）＋ RV — 解剖過得了，生理過不了一樣 code

4 Awake / DSI — 保留自呼吸的兩條路

Awake (ATI) · DAS 2019 DSI
適應 解剖難 · 預期 CICO · C-spine Agitated · preox 做不到
意識 完全清醒 半 sedate
用藥 Lido 4% 表麻 + Dex/Ket 低劑量 Ketamine 1 mg/kg
下一步 FOI / VL · 不上 paralytic NIV preox → paralytic → 插
共通：保留自呼吸 + airway reflex 當安全網
Awake STOP：Sedation 輕 · Topicalisation（lido max 9 mg/kg）· Oxygen NC 15L · Performance VL/FOI
⚠ 避免：Propofol / Midazolam（會丟氣道）· 表麻不夠硬插 → vomit / laryngospasm

5 Failed Airway Algorithm

Intubation failed?
  │
  ├─ Can oxygenate  (BVM / LMA OK，SpO₂ 撐得住)
  │     → "STOP & THINK" · 時間是朋友
  │     └─ Optimize ≤ 3 tries：ELM · bougie · VL · 換刀 · 換人
  │         不行 → LMA (Plan B) / 喚醒 / 後送
  │
  └─ Cannot oxygenate — CICO ★  (SpO₂ 一路掉)
        → 時間是敵人 · 60 秒內動手
        └─ eFONA · Surgical cricothyrotomy
            Scalpel — Bougie — Tube  (10# blade · 6.0 ETT)
3-3-1 rule：3 attempts · 3 operators · 1 decision to cric． 喊出「This is a CICO situation」=團隊立刻切 surgical airway mode

6 SALAD — Suction-Assisted Laryngoscopy & Airway Decontamination

  • 適應：大量 嘔吐 / 出血 / 分泌物 的 airway（GI bleed、溺水、中毒）
  • 器材：rigid suction（Yankauer 或 DuCanto catheter）+ VL 優先
  1. 左手 laryngoscope，右手 suction 先進去 hypopharynx 持續吸
  2. 看到 glottis 後，suction 從嘴角左側留置在食道口繼續吸
  3. ETT 沿右側送入聲門
原則：Suction first, then look — 永遠不要在血/嘔吐物海裡找聲門
